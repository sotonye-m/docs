Yativo has two [Model Context Protocol](https://modelcontextprotocol.io) servers. Pick the one that matches what your assistant needs to do.

| | Docs MCP | Fiat MCP |
|---|---|---|
| **What it does** | Searches and cites these docs | Checks balances, deposits, payouts and beneficiaries, and quotes and sends payouts |
| **Acts on** | Public docs only | Your Yativo Fiat business account |
| **Moves money** | No | Yes, with your approval for each payout |
| **Connect with** | `https://docs.yativo.com/mcp` | `https://api.yativo.com/mcp` |
| **Sign in with** | Nothing | OAuth sign-in or an [API key](/yativo-fiat/api-keys) |
| **Guide** | Below | [Fiat MCP server](/yativo-fiat/mcp-server) |

<Tip>
  Start with the Docs MCP while you build. It needs no credentials and answers questions from the current docs instead of your assistant's training data.
</Tip>

## Docs MCP server

Every page on this site is available to AI assistants at:

```
https://docs.yativo.com/mcp
```

It's read-only and needs no API key. Your assistant can search the Fiat and Crypto docs, open the right reference page and cite it.

| Capability | Description |
|---|---|
| Search and retrieval | Full-text search and page retrieval across the Yativo Fiat and Crypto docs |
| Resources | Extra guidance the assistant reads when relevant |
| `submit_feedback` | Reports an incorrect, outdated or confusing page to the docs team |

### Claude Code

```bash
claude mcp add --transport http yativo-docs https://docs.yativo.com/mcp
```

### Claude Desktop and claude.ai

Go to **Settings → Connectors → Add custom connector** and enter `https://docs.yativo.com/mcp`.

### Cursor

Add to your `mcp.json`, then reload Cursor:

```json
{
  "mcpServers": {
    "yativo-docs": {
      "url": "https://docs.yativo.com/mcp"
    }
  }
}
```

### Example prompts

- *"Using the Yativo docs, how do I create a virtual account for a customer?"*
- *"What fields does the send-money quote endpoint require?"*
- *"Show me how to verify a Yativo webhook signature in Python."*

## Key capabilities

| Capability | Description |
|---|---|
| Multi-currency accounts | Hold and move money in 50+ currencies |
| Cross-border transfers | Send funds internationally via a single API call |
| Virtual accounts | Issue receiving accounts per customer or transaction |
| Beneficiary management | Store and reuse recipient bank details across countries |
| Webhooks | Real-time event notifications for platform activity |
| B2B customer management | Create and manage sub-accounts for your own customers |

## Authentication

Send `X-Api-Key` and `X-Api-Secret` on every request, from an IP on the key's whitelist. See [Authentication](/yativo-fiat/authentication).

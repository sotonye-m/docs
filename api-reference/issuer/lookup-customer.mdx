---
title: "Lookup Customer"
api: "GET /v1/card-issuer/lookup-customer"
description: "Find a customer record by any identifier"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField query="customer_id" type="string">Yativo customer ID.</ParamField>

<ParamField query="card_id" type="string">Card ID from card creation.</ParamField>

<ParamField query="external_id" type="string">Your external reference set at onboarding.</ParamField>

<ParamField query="email" type="string">Customer email address.</ParamField>

<Note>
  One of `customer_id`, `card_id`, `external_id`, or `email` is required.
</Note>

<RequestExample>
```bash cURL
curl -X GET 'https://crypto-api.yativo.com/api/v1/card-issuer/lookup-customer?external_id=your_user_id_8821' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```
</RequestExample>

<ResponseExample>
```json 200 Found
{
  "success": true,
  "data": {
    "customer_id": "6627f3a2c5d4e100123abcde",
    "external_id": "your_user_id_8821",
    "email": "priya@yourapp.com",
    "currency": "EUR",
    "token": "EURe",
    "wallet_ready": true,
    "cards_count": 1,
    "created_at": "2026-04-01T10:00:00.000Z"
  }
}
```

```json 404 Not found
{
  "success": false,
  "error": "CUSTOMER_NOT_FOUND"
}
```
</ResponseExample>

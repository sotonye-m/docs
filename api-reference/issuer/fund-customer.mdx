---
title: "Fund Customer Card"
api: "POST /v1/card-issuer/fund-customer"
description: "Push funds from your master wallet to a customer's card wallet. Only available for `master_wallet` programs."
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<Note>
  Supply exactly one customer identifier. The customer must have completed onboarding
  (KYC approved, wallet ready) before funding.
</Note>

<ParamField body="customer_id" type="string">
  Yativo-generated customer ID returned at onboarding.
</ParamField>

<ParamField body="card_id" type="string">
  Card ID from card creation.
</ParamField>

<ParamField body="external_id" type="string">
  Your own reference (`external_customer_id`) set at onboarding.
</ParamField>

<ParamField body="email" type="string">
  Customer email address.
</ParamField>

<ParamField body="amount" type="number" required>
  Amount in USD. Interpretation depends on `pricing_mode`.
</ParamField>

<ParamField body="source_chain" type="string" required>
  Master wallet to debit. `SOL` or `XDC`.
</ParamField>

<ParamField body="pricing_mode" type="string">
  `send_x` (default) — debit exactly `amount`; customer receives less after fees.
  `receive_x` — customer receives exactly `amount`; master wallet debited more.
</ParamField>

<ParamField body="destination_token" type="string">
  Optional target currency (`USDC`, `EURe`, `GBPe`). Defaults to the customer's card
  currency. Must match — mismatches return an error with the correct required token.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://crypto-api.yativo.com/api/v1/card-issuer/fund-customer' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "external_id": "your_user_id_8821",
    "amount": 200,
    "source_chain": "SOL",
    "pricing_mode": "receive_x"
  }'
```
</RequestExample>

<ResponseExample>
```json 200 Initiated
{
  "success": true,
  "message": "Customer funding initiated",
  "data": {
    "bridge_id": "bridge_01HX9KZMB3F7VNQ",
    "status": "initiated",
    "source": { "chain": "SOL", "amount": 201.80 },
    "destination": { "token": "EURe", "amount": 200.00 },
    "pricing_mode": "receive_x",
    "estimated_time": "2-10 minutes",
    "created_at": "2026-04-01T12:00:00.000Z"
  }
}
```

```json 400 Token mismatch
{
  "success": false,
  "error": "TOKEN_MISMATCH",
  "message": "This customer's card requires EURe. You requested USDC. Please swap to EURe first.",
  "required_token": "EURe",
  "requested_token": "USDC"
}
```

```json 400 Daily limit exceeded
{
  "success": false,
  "error": "DAILY_LIMIT_EXCEEDED",
  "message": "Daily funding limit exceeded. Used: $48200.00, limit: $50000"
}
```
</ResponseExample>

---
title: "List Customers"
api: "GET /v1/yativo-card/customers/cards"
description: "List all customer cards onboarded under your issuer program"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField query="page" type="integer">Page number. Defaults to `1`.</ParamField>

<ParamField query="limit" type="integer">Results per page. Defaults to `20`, max `100`.</ParamField>

<ParamField query="status" type="string">
  Filter by onboarding status. One of: `otp_requested`, `otp_verified`, `kyc_initiated`,
  `kyc_completed`, `card_created`, `active`.
</ParamField>

<ParamField query="external_customer_id" type="string">
  Filter by your external reference.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://crypto-api.yativo.com/api/v1/yativo-card/customers/cards?status=active' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```
</RequestExample>

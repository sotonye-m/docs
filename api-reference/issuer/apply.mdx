---
title: "Apply for Issuer Program"
api: "POST /v1/card-issuer/apply"
description: "Submit an application to join the Yativo Card Issuer Program"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField body="funding_structure" type="string" required>
  Funding model for the program.

  | Value | Description |
  |---|---|
  | `master_wallet` | You maintain a shared balance and push funds to each customer card. Best for platforms that want centralised control over top-ups. |
  | `non_master` | Each customer funds their own card wallet independently. Best for self-service crypto-funded cards. |
</ParamField>

<ParamField body="iban_enabled" type="boolean" required>
  Whether to enable IBAN functionality for cardholders in your program.
</ParamField>

<Note>
  The Issuer Program requires prior eligibility approval. Contact your account manager or [support@yativo.com](mailto:support@yativo.com) to request access before applying.
</Note>

<RequestExample>
```bash cURL
curl -X POST 'https://crypto-api.yativo.com/api/v1/card-issuer/apply' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "funding_structure": "master_wallet",
    "iban_enabled": false
  }'
```
</RequestExample>

<ResponseExample>
```json 201 Created
{
  "success": true,
  "message": "Application submitted successfully",
  "data": {
    "application_id": "6627f3a2c5d4e100123abcde",
    "status": "pending",

```

```json 403 Not eligible
{
  "success": false,
  "error": "NOT_ELIGIBLE",
  "message": "Your account is not yet eligible for the Card Issuer Program. Contact support to request access."

```
</ResponseExample>

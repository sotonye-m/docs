---
title: "Funding History"
api: "GET /v1/card-issuer/funding-history"
description: "List all customer funding transactions initiated from your master wallet"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField query="page" type="integer">Page number. Defaults to `1`.</ParamField>

<ParamField query="limit" type="integer">Results per page. Defaults to `20`, max `100`.</ParamField>

<ParamField query="status" type="string">
  Filter by status: `initiated`, `pending`, `completed`, `failed`.
</ParamField>

<ParamField query="customer_id" type="string">Filter by customer ID.</ParamField>

<ParamField query="chain" type="string">Filter by source chain: `SOL` or `XDC`.</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://crypto-api.yativo.com/api/v1/card-issuer/funding-history?status=completed&limit=20' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```
</RequestExample>

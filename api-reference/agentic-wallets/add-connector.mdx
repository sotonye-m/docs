---
title: "Add Connector"
api: "POST /v1/agentic-wallets/{walletId}/connectors"
description: "Create a connector (agent API key) for an agentic wallet"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField path="walletId" type="string" required>
  The wallet to add a connector to. The wallet must be active.
</ParamField>

<ParamField body="connector_type" type="string" required>
  One of `anthropic`, `openai`, `polymarket`, `kalshi`, `openclaw`, `custom`.
</ParamField>

<ParamField body="name" type="string">
  Human-readable name, e.g. "Claude Agent". Defaults to the connector type.
</ParamField>

<ParamField body="description" type="string">
  Optional description.
</ParamField>

<ParamField body="allowed_capabilities" type="string[]" default="[&quot;transfer&quot;]">
  What the agent may do: `transfer`, `x402`, `prediction_market`.
</ParamField>

<ParamField body="max_per_transaction" type="number">
  Max USD per transaction. Can't exceed `max_daily_amount`.
</ParamField>

<ParamField body="max_daily_amount" type="number">
  Max USD per day. Can't exceed `max_monthly_amount`.
</ParamField>

<ParamField body="max_monthly_amount" type="number">
  Max USD per month.
</ParamField>

<ParamField body="allowed_assets" type="string[]">
  Restrict to these assets. Empty allows all.
</ParamField>

<ParamField body="allowed_chains" type="string[]">
  Restrict to these chains. Empty allows all.
</ParamField>

<ParamField body="allowed_ips" type="string[]">
  Only accept agent requests from these IPs.
</ParamField>

<ParamField body="allowed_domains" type="string[]">
  Only accept agent requests from these domains.
</ParamField>

<ParamField body="webhook_url" type="string">
  Receive this connector's events. A webhook secret is returned once when set.
</ParamField>

<ParamField body="prediction_market_config" type="object">
  Limits for the `prediction_market` capability: `max_position_usd` (largest trade), `allowed_categories` and `allowed_providers` (empty allows all).
</ParamField>

<RequestExample>
```bash
curl -X POST 'https://crypto-api.yativo.com/api/v1/agentic-wallets/aw_01abc123/connectors' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "connector_type": "anthropic",
    "name": "Claude Agent",
    "allowed_capabilities": ["transfer", "prediction_market"],
    "max_per_transaction": 50,
    "max_daily_amount": 500,
    "max_monthly_amount": 5000,
    "prediction_market_config": { "max_position_usd": 25 }
  }'
```
</RequestExample>

<Warning>
  The `api_key` is shown **only once**. Store it securely. If lost, revoke the connector and create a new one.
</Warning>

---
title: "Freeze Customer Card"
api: "POST /v1/yativo-card/customers/{yativoCardId}/cards/{cardId}/freeze"
description: "Temporarily freeze a customer's card to block new transactions"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField path="yativoCardId" type="string" required>
  The customer's `yativo_card_id`.
</ParamField>

<ParamField path="cardId" type="string" required>
  The card ID to freeze.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://crypto-api.yativo.com/api/v1/yativo-card/customers/yativo_card_customer_8f9a..._1769031332068/cards/b2dc97ab-03f9-49eb-c72f-95be13815278/freeze' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json'
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "success": true,
  "message": "Card frozen successfully",
  "data": {
    "card_id": "b2dc97ab-03f9-49eb-c72f-95be13815278",
    "is_frozen": true,
    "frozen_at": "2026-04-01T13:00:00.000Z"
  }
}
```
</ResponseExample>

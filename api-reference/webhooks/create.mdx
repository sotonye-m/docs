---
title: "Create Webhook"
api: "POST /v1/webhook/create-webhook"
description: "Register a webhook endpoint to receive real-time event notifications"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField body="webhook_url" type="string" required>
  The HTTPS URL that will receive webhook POST requests.
</ParamField>

<ParamField body="subscribed_events" type="array">
  Array of event slugs to subscribe to. Omit to subscribe to no events by default, or combine with `receive_all_events: true` to receive everything. Example slugs:
  - `deposit.detected`
  - `deposit.confirmed`
  - `transaction.confirmed`
  - `transaction.failed`
  - `swap.completed`
  - `swap.failed`
</ParamField>

<ParamField body="webhook_name" type="string">
  A human-readable name for this webhook.
</ParamField>

<ParamField body="receive_all_events" type="boolean">
  Set to `true` to receive every event type regardless of `subscribed_events`. Default: `false`.
</ParamField>

<RequestExample>
```bash
curl -X POST 'https://crypto-api.yativo.com/api/v1/webhook/create-webhook' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "webhook_url": "https://your-app.com/webhooks/yativo",
    "subscribed_events": ["deposit.detected", "deposit.confirmed", "transaction.confirmed", "transaction.failed", "swap.completed", "swap.failed"],
    "webhook_name": "Production webhook"
  }'
```
</RequestExample>

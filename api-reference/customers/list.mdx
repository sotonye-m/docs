---
title: "List Customers"
api: "POST /v1/customers/get-customers"
description: "List your wallet customers with balances"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField body="search" type="string">
  Matches username, email, or a wallet address.
</ParamField>

<ParamField body="page" type="number" default="1">
  Page number.
</ParamField>

<ParamField body="limit" type="number" default="20">
  Results per page.
</ParamField>

<RequestExample>
```bash
curl -X POST 'https://crypto-api.yativo.com/api/v1/customers/get-customers' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{ "page": 1, "limit": 20 }'
```
</RequestExample>

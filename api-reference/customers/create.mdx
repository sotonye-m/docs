---
title: "Create Customer"
api: "POST /v1/customers/create-customer"
description: "Create a wallet customer"
authMethod: "bearer"
---

<ParamField header="Authorization" type="string" required>
  Bearer token: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField body="username" type="string" required>
  Display name for the customer.
</ParamField>

<ParamField body="email" type="string" required>
  Customer email address. Must be unique.
</ParamField>

<RequestExample>
```bash
curl -X POST 'https://crypto-api.yativo.com/api/v1/customers/create-customer' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{ "username": "Acme Corp", "email": "billing@acme.com" }'
```
</RequestExample>

<ResponseExample>
```json
{
  "status": true,
  "message": "Customer created successfully !",
  "data": {
    "_id": "6650a1f2c3d4e5f6a7b8c9d0",
    "username": "Acme Corp",
    "email": "billing@acme.com",
    "phone_number": "",
    "user_id": "664f0e1d2c3b4a5968778695",
    "createdAt": "2026-09-30T10:00:00.000Z",
    "updatedAt": "2026-09-30T10:00:00.000Z"
  }
}
```
</ResponseExample>

The customer's `_id` is the `customer_id` used by every other customer endpoint. A `customer.created` webhook is sent on success.

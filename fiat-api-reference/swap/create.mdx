---
title: "Run Swap"
description: "Move balance from one of your wallets to another"
openapi: "POST https://api.yativo.com/api/v1/wallet/swap"
---

Debits the source wallet and credits the destination wallet in one step. Keep the `reference` from the response to look the swap up later.

<Note>
  Retrying with the same `Idempotency-Key` returns the original swap. No second swap runs.
</Note>

See [Currency Swap](/yativo-fiat/swap#errors) for the error messages.

---
title: "Delete Virtual Account"
description: "Permanently delete a virtual account"
openapi: "openapi-fiat.yaml DELETE /business/virtual-account/delete-virtual-account/{account_id}"
---

Permanently deletes a virtual account. This action is irreversible.

```
DELETE /v1/business/virtual-account/delete-virtual-account/{account_id}
```

<RequestExample>
```bash cURL
curl -X DELETE 'https://api.yativo.com/api/v1/business/virtual-account/delete-virtual-account/acct_xxxxxx' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET'
```
</RequestExample>

<ResponseExample>
```json Success
{
  "status": "success",
  "status_code": 200,
  "message": "Request successful",
  "data": {
    "message": "Virtual account deleted successfully",
    "account_id": "acct_xxxxxx"
  }
}
```

```json Not found
{
  "status": "failed",
  "status_code": 404,
  "message": "Request failed.",
  "data": { "error": "Account with the provided ID does not exists" }
}
```
</ResponseExample>

The account stops accepting funds, and a [`virtual_account.deleted`](/yativo-fiat/webhooks#virtual_accountdeleted) webhook is sent.

| HTTP | `data.error` | Cause |
|---|---|---|
| 404 | `Account with the provided ID does not exists` | The account doesn't exist or isn't yours. |
| 400 | `Unable to delete virtual account, please try again later` | The account couldn't be closed. Retry later. |

<Warning>
  Deleting a virtual account is permanent and cannot be undone. Ensure any pending transactions are resolved before deleting.
</Warning>

---
title: "List Currencies and Endorsements"
description: "Virtual account currencies and the endorsement each needs"
openapi: "openapi-fiat.yaml GET /business/virtual-account/currencies-and-endorsements"
---

Before issuing a virtual account, check that the customer's endorsement for the currency is `approved`. See [Track verification with endorsements](/yativo-fiat/kyc#track-verification-with-endorsements).

<RequestExample>
```bash cURL
curl -X GET 'https://api.yativo.com/api/v1/business/virtual-account/currencies-and-endorsements' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET'
```
</RequestExample>

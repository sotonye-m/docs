---
title: "Create Virtual Account"
description: "Issue a virtual bank account to a customer to receive funds"
openapi: "openapi-fiat.yaml POST /business/virtual-account/create"
---

Create a virtual bank account for a customer. The customer must have an approved endorsement for the currency (see `GET /business/virtual-account/currencies-and-endorsements`) before a virtual account can be issued.

```
POST /v1/business/virtual-account/create
```

<Note>
  Requires an `Idempotency-Key` header. Each customer can hold one virtual account per currency.
</Note>

<RequestExample>
```bash Brazil (PIX / BRL)
curl -X POST 'https://api.yativo.com/api/v1/business/virtual-account/create' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: unique-key-here' \
  -d '{
    "currency": "BRL"
  }'
```

```bash USD (ACH)
curl -X POST 'https://api.yativo.com/api/v1/business/virtual-account/create' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: unique-key-here' \
  -d '{
    "customer_id": "da44a3e6-eb5d-429f-8d17-357aa5a6cdf2",
    "currency": "USD"
  }'
```
</RequestExample>

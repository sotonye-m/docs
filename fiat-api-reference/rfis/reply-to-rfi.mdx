---
title: "Reply to RFI"
description: "Submit a complete answer for an open RFI in one request"
openapi: "openapi-fiat.yaml POST /business/rfis/{id}/responses"
---

Submit your answers for an open RFI in **one request**. The body must include **every** `requested_items[].id`, each with at least one valid field from that item's `response_types`.

<Warning>
  A submission must include every requested item. A successful response records the submission for review, but does not itself change the RFI's `status` or `response_required` fields. Check the returned data for `merchant_responses_submitted_at`.
</Warning>

Yativo reviews your response before it is processed further.

```
POST https://api.yativo.com/api/v1/business/rfis/{id}/responses
```

To save partial answers without submitting the RFI, use `PUT /business/rfis/{id}/draft-responses`. Saving a draft does not submit it for review.

<RequestExample>
```bash cURL
curl -X POST 'https://api.yativo.com/api/v1/business/rfis/42/responses' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: rfi-reply-42-v1' \
  -d '{
    "responses": {
      "55555555-6666-4777-8888-999999999999": {
        "free_text_explanation": "Customer explanation here."
      }
    }
  }'
```
</RequestExample>

Returns `422` if the RFI is closed or any requested item is missing or incomplete.

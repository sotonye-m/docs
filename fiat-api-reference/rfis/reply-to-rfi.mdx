---
title: "Reply to RFI"
description: "Send answers for an open RFI (reviewed by Yativo before submission upstream)"
openapi: "openapi-fiat.yaml PUT /business/rfis/{id}/draft-responses"
---

Submit or update your answers for an open RFI. You can send a partial reply (merged into any existing answers) or answer every requested item in one call. Yativo reviews before anything is sent upstream.

```
PUT https://api.yativo.com/api/v1/business/rfis/{id}/draft-responses
```

<RequestExample>
```bash cURL
curl -X PUT 'https://api.yativo.com/api/v1/business/rfis/42/draft-responses' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: rfi-reply-42-v1' \
  -d '{
    "responses": {
      "523bc014-8d2e-4d0b-b5fc-5ea407168f7d": {
        "free_text_explanation": "Customer explanation here."
      }
    }
  }'
```
</RequestExample>

Returns `422` if the RFI is closed.

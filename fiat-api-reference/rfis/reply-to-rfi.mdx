---
title: "Reply to RFI"
description: "Send a complete answer for an open RFI in one request"
openapi: "openapi-fiat.yaml PUT /business/rfis/{id}/draft-responses"
---

Submit your answers for an open RFI in **one request**. The body must include **every** `requested_items[].id`, each with at least one valid field from that item's `response_types`.

<Warning>
  A reply is **final**. You can't send a partial reply or change answers later on the same open period. After a successful call, `responses_submitted_at` is set and `response_required` becomes `false` while Yativo reviews. To answer again, wait until Yativo reopens the RFI (`response_required` is `true` and `status` is `action_required` again).
</Warning>

Yativo reviews your reply before anything is sent upstream.

```
PUT https://api.yativo.com/api/v1/business/rfis/{id}/draft-responses
```

You can also use `POST /business/rfis/{id}/responses` with the same JSON body and the same rules.

<RequestExample>
```bash cURL
curl -X PUT 'https://api.yativo.com/api/v1/business/rfis/42/draft-responses' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: rfi-reply-42-v1' \
  -d '{
    "responses": {
      "2095d3da-2761-4d30-93e6-b46018bf576a": {
        "free_text_explanation": "Customer explanation here."
      }
    }
  }'
```
</RequestExample>

Returns `422` if the RFI is closed, if a reply was already submitted and Yativo hasn't reopened it, or if any requested item is missing or incomplete.

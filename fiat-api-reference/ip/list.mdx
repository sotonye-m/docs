---
title: "List Allowlisted IPs"
description: "Retrieve all IP addresses currently allowlisted for API access"
---

Returns all IP addresses registered on your account's allowlist.

```
GET https://api.yativo.com/api/v1/ip
```

<RequestExample>
```bash cURL
curl -X GET 'https://api.yativo.com/api/v1/ip' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```
</RequestExample>

<ResponseExample>
```json Success
{
  "status": "success",
  "status_code": 200,
  "message": "Request successful",
  "data": [
    {
      "id": "ip-a1b2c3",
      "ip_address": "203.0.113.10",
      "label": "Production server",
      "created_at": "2026-04-01T10:00:00.000000Z"
    }
  ]
}
```
</ResponseExample>

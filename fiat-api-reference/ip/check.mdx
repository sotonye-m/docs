---
title: "Check IP Whitelist"
description: "See the IP Yativo detects for your request and whether it can use your API key"
openapi: "GET https://api.yativo.com/api/v1/ip-whitelist/check"
---

Call this from the server that uses your API key. It never blocks the request, so you can run it any time, including right after changing a key's allowed IPs.

- `key_usage.allowed_server` is `true` when the calling server can use the key.
- `key_usage.request_ip` is the IP to whitelist if it isn't the one you expected.
- Add `?ip=<address>` to test a server you haven't deployed yet.

To add or change IPs, use **Developers → API Keys** in the dashboard. See [IP whitelisting](/yativo-fiat/ip-allowlist).

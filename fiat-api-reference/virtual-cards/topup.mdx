---
title: "Top Up Card"
description: "Fund a virtual card from your USD wallet balance"
openapi: "openapi-fiat.yaml POST /customer/virtual/cards/topup"
---

Adds funds to a virtual card. The amount is always debited from your USD wallet.

```
POST https://api.yativo.com/api/v1/customer/virtual/cards/topup
```

<Note>
  Requires an `Idempotency-Key` header.
</Note>

<RequestExample>
```bash cURL
curl -X POST 'https://api.yativo.com/api/v1/customer/virtual/cards/topup' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: topup-card-001' \
  -d '{
    "cardId": "card_01HX9KZMB3F7VNQP8R2WDGT4E5",
    "amount": 100.00
  }'
```
</RequestExample>

<ResponseExample>
```json Success
{
  "status": "success",
  "status_code": 200,
  "message": "Card topped up successfully",
  "data": {
    "card_id": "card_01HX9KZMB3F7VNQP8R2WDGT4E5",
    "amount_added": "100.00",
    "new_balance": "250.00",
    "currency": "USD"
  }
}
```
</ResponseExample>

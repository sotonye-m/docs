---
title: "Create Card Link Theme"
description: "Brand the card link page and its emails with your logo, font, colours and copy"
openapi: "openapi-fiat.yaml POST /corporate-card/card-link/themes"
---

Creates a theme for the card link page and its emails. Pick it per link with `theme_id`, or set `is_default` to use it everywhere. See [Brand the page](/yativo-fiat/corporate-card-links#brand-the-page).

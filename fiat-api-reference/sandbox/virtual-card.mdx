---
title: "Simulate a virtual card event (sandbox only)"
description: "Fire a virtualcard.* event on a card you own. Sandbox only."
openapi: "openapi-fiat.yaml POST /sandbox/virtual-cards/{cardId}/simulate"
---

Updates local card status where the event would in production and sends the matching `virtualcard.*` webhook. It never calls the card issuer.

```
POST /sandbox/virtual-cards/{cardId}/simulate
```

<Warning>
  Sandbox only. Call `https://smtp.yativo.com/api/v1`. Production returns `404` with `Not found`.
</Warning>

The card must belong to your business. Omit `event` to default to `virtualcard.transaction.settlement`, or `virtualcard.transaction.declined` when `outcome` is `fail`.

<RequestExample>
```bash cURL
curl -X POST 'https://smtp.yativo.com/api/v1/sandbox/virtual-cards/card_123/simulate' \
  -H 'X-Api-Key: YOUR_SANDBOX_API_KEY' \
  -H 'X-Api-Secret: YOUR_SANDBOX_API_SECRET' \
  -H 'Content-Type: application/json' \
  -d '{
    "event": "virtualcard.transaction.settlement",
    "amount": 12.5,
    "outcome": "success"
  }'
```
</RequestExample>

See [Virtual cards](/yativo-fiat/webhooks#virtual-cards) and every sandbox simulation endpoint in [Sandbox](/yativo-fiat/sandbox#sandbox-simulation-endpoints).

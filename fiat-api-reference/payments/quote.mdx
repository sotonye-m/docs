The exchange rate endpoint uses **POST**, not GET:

```
POST https://api.yativo.com/api/v1/exchange-rate
```

Pass `from_currency`, `to_currency`, and `amount` as a JSON body. Returns the current rate, fee breakdown, and a `quote_id` that can be used in `POST /sendmoney` or `POST /wallet/payout` to guarantee the quoted rate for 5 minutes.

See [Exchange Rate reference](/fiat-api-reference/payments/exchange-rate) for the full parameter reference and response examples.

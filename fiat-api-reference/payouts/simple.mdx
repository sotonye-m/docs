---
title: "Single Payout"
description: "Send one payment to a saved beneficiary payment method"
openapi: "openapi-fiat.yaml POST /payout/simple"
---

Send a single payment to a saved beneficiary. Debits your wallet at the time of submission.

```
POST https://api.yativo.com/api/v1/payout/simple
```

<Note>
  Requires `Idempotency-Key` header. Your wallet is charged immediately on submission.
</Note>

`/payout/simple` works like [`POST /wallet/payout`](/fiat-api-reference/payments/payout) with `beneficiary_details_id` in place of `payment_method_id`. To fix the amount the customer receives (`amount_type: "receive"`), use `/wallet/payout`.

Every payout goes through compliance checks before it's sent. If you include an invoice, it's reviewed with the payout, so make sure its total and beneficiary match. A payout that needs a closer look stays `pending` until the review is finished.

<RequestExample>
```bash cURL
curl -X POST 'https://api.yativo.com/api/v1/payout/simple' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: payout-simple-001' \
  -d '{
    "debit_wallet": "USD",
    "amount": 250,
    "beneficiary_details_id": 42,
    "customer_id": "da44a3e6-eb5d-429f-8d17-357aa5a6cdf2",
    "reference": "INV-2026-0042"
  }'
```
</RequestExample>

---
title: "List Webhooks"
description: "Retrieve all configured webhook endpoints for your business account"
---

Returns all configured webhook endpoints for your business account.

```
GET /business/webhook
```

<RequestExample>
```bash cURL
curl -X GET 'https://api.yativo.com/api/v1/business/webhook' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```
</RequestExample>

<ResponseExample>
```json Success
{
  "status": "success",
  "status_code": 200,
  "message": "Request successful",
  "data": [
    {
      "id": "wh_a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "url": "https://your-app.com/webhooks/yativo",
      "events": "general",
      "created_at": "2026-04-01T10:00:00.000000Z"
    }
  ]
}
```
</ResponseExample>

---
title: "Add Beneficiary"
description: "Save a recipient's account details for one payout method"
openapi: "openapi-fiat.yaml POST /beneficiaries/payment-methods"
---

Save a recipient's account details as a beneficiary. The `payment_data` fields depend on the payout method. Get them from `GET /beneficiary/form/show/{payment_method_id}`. Use the returned `id` in payouts and quotes.

```
POST /v1/beneficiaries/payment-methods
```

<Note>
  Requires an `Idempotency-Key` header.
</Note>

## Payment data examples

<Accordion title="Chile — Bank Transfer">
```json
{
  "account_number": "12345678",
  "bank_code": "001",
  "account_type": "checking",
  "rut": "12.345.678-9"
}
```
</Accordion>

<Accordion title="Mexico — SPEI">
```json
{
  "clabe": "012345678901234567"
}
```
</Accordion>

<Accordion title="Brazil — PIX / Bank Transfer">
```json
{
  "account_number": "12345-6",
  "branch_number": "0001",
  "bank_code": "341",
  "account_type": "checking",
  "cpf": "123.456.789-00"
}
```
</Accordion>

<RequestExample>
```bash cURL — Chile Bank Transfer
curl -X POST 'https://api.yativo.com/api/v1/beneficiaries/payment-methods' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: pm-create-001' \
  -d '{
    "gateway_id": 42,
    "currency": "CLP",
    "nickname": "Maria CLP Account",
    "payment_data": {
      "account_number": "12345678",
      "bank_code": "001",
      "account_type": "checking",
      "rut": "12.345.678-9"
    }
  }'
```

---
title: "Create order"
description: "Create a checkout order and get a checkout_url for the buyer"
openapi: "openapi-fiat.yaml POST /card-checkout/orders"
---

You set the amount; the buyer cannot change it. Redirect them to `checkout_url` exactly as returned. **Only the `card_checkout.order.paid` webhook means the buyer paid.**

The checkout link expires after 60 minutes. `platform_fee`, `reserve` and `net_amount` are fixed when the order is created.

See [Create an order](/yativo-fiat/card-checkout#step-2-create-an-order).

<RequestExample>
```bash cURL
curl -X POST 'https://api.yativo.com/api/v1/card-checkout/orders' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Idempotency-Key: 3f1c2a1e-8b7d-4c1e-9f0a-6d2b5e7c9a10' \
  -H 'Content-Type: application/json' \
  -d '{
    "customer_id": "4f0c1e1a-8d2b-4c7e-9b1a-3e5f6a7b8c9d",
    "amount": "49.99",
    "currency": "USD",
    "description": "Pro plan, 1 month",
    "reference": "INV-10023",
    "customer_email": "ada@example.com",
    "success_url": "https://shop.example.com/thanks",
    "cancel_url": "https://shop.example.com/cart",
    "metadata": { "plan": "pro" }
  }'
```
</RequestExample>

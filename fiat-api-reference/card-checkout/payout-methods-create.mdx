---
title: "Create payout method"
description: "Save a payout destination for this customer"
openapi: "openapi-fiat.yaml POST /card-checkout/customers/{customer_id}/payout-methods"
---

Sensitive details are vaulted in transit and never stored by Yativo. `supported_payout_method_id` and `fields` come from [List supported payout methods](/fiat-api-reference/card-checkout/supported-payout-methods). The method is saved on this customer only.

See [Let a customer withdraw their sales](/yativo-fiat/card-checkout#let-a-customer-withdraw-their-sales).

<RequestExample>
```bash cURL
curl -X POST 'https://api.yativo.com/api/v1/card-checkout/customers/4f0c1e1a-8d2b-4c7e-9b1a-3e5f6a7b8c9d/payout-methods' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Idempotency-Key: 9e2d6a14-5c3b-4f8e-a7d1-0b4c2e6f8a35' \
  -H 'Content-Type: application/json' \
  -d '{
    "supported_payout_method_id": "podst_ach",
    "nickname": "Ops checking",
    "fields": {
      "fld_bank_account_number": "8825310472",
      "fld_bank_routing_number": "111000025",
      "fld_bank_account_type": "checking"
    }
  }'
```
</RequestExample>

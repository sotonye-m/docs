---
title: "List withdrawals"
description: "List this customer's Card Checkout withdrawals and their Yativo balance"
openapi: "openapi-fiat.yaml GET /card-checkout/customers/{customer_id}/payouts"
---

Newest first. `balance.available` is the only amount that can still be withdrawn.

See [Let a customer withdraw their sales](/yativo-fiat/card-checkout#let-a-customer-withdraw-their-sales).

<RequestExample>
```bash cURL
curl 'https://api.yativo.com/api/v1/card-checkout/customers/4f0c1e1a-8d2b-4c7e-9b1a-3e5f6a7b8c9d/payouts' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET'
```
</RequestExample>

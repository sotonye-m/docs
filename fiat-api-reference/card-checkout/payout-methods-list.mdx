---
title: "List payout methods"
description: "List the payout destinations this customer saved"
openapi: "openapi-fiat.yaml GET /card-checkout/customers/{customer_id}/payout-methods"
---

Masked destinations this customer added on the withdrawal page. Full account numbers are never returned. Another customer's methods are not listed.

See [Let a customer withdraw their sales](/yativo-fiat/card-checkout#let-a-customer-withdraw-their-sales).

<RequestExample>
```bash cURL
curl 'https://api.yativo.com/api/v1/card-checkout/customers/4f0c1e1a-8d2b-4c7e-9b1a-3e5f6a7b8c9d/payout-methods' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET'
```
</RequestExample>

---
title: "Get selling customer"
description: "Read a customer's card_checkout endorsement"
openapi: "openapi-fiat.yaml GET /card-checkout/customers/{customer_id}"
---

Same shape as the submit-endorsement response. When the endorsement has not been submitted, `endorsement_status` is `not_started`. When it is `approved`, the response includes `balance` (`available`, `pending`, `reserved`) and `whop_withdrawal_url`. Only `available` can be withdrawn.

```
GET https://api.yativo.com/api/v1/card-checkout/customers/{customer_id}
```

See [Follow the endorsement](/yativo-fiat/card-checkout#follow-the-endorsement).

<RequestExample>
```bash cURL
curl 'https://api.yativo.com/api/v1/card-checkout/customers/4f0c1e1a-8d2b-4c7e-9b1a-3e5f6a7b8c9d' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET'
```
</RequestExample>

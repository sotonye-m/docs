title: "Update Individual KYC (Partial)"
description: "Change some fields of an individual KYC submission"
openapi: "openapi-fiat.yaml PATCH /individual-kyc/{customerId}"

Send only the fields you're changing. Field names and rules match [Submit Individual KYC](/fiat-api-reference/kyc/submit-individual). Use the [lookups](/fiat-api-reference/kyc-lookups/countries) to fill address and ID fields.

---
title: "Payouts"
description: "Send payments to saved beneficiaries"
---

Use `POST /payout/simple` to send a payment to one beneficiary. It requires a saved beneficiary with an attached payment method. See [Send Money](/yativo-fiat/send-money) for setting up beneficiaries.

<Note>
  All payout requests require an `Idempotency-Key` header. Your wallet balance is charged when the payout is submitted.
</Note>

---

## Single Payout

Send one payment to a saved beneficiary payment method.

```
POST https://api.yativo.com/api/v1/payout/simple
```

<ParamField body="debit_wallet" type="string" required>
  The wallet currency to debit, for example `"USD"`.
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to send in the debit wallet currency.
</ParamField>

<ParamField body="beneficiary_details_id" type="number" required>
  The beneficiary `id` (from [Add Beneficiary](/fiat-api-reference/beneficiaries/payment-methods-create)).
</ParamField>

<ParamField body="customer_id" type="string" required>
  The customer the payout is for. If the beneficiary belongs to a customer, it must be that customer.
</ParamField>

<ParamField body="beneficiary_id" type="string">
  Optional. The beneficiary that owns the payment method.
</ParamField>

<ParamField body="reference" type="string">
  Payment reference shown to the recipient's bank, up to 250 characters. Some payout rails shorten it or remove unsupported characters.
</ParamField>

`/payout/simple` also accepts `quote_id`, `invoice` and `invoice_url`, like [`POST /wallet/payout`](/fiat-api-reference/payments/payout).

<RequestExample>
```bash cURL
curl -X POST 'https://api.yativo.com/api/v1/payout/simple' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET' \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: payout-simple-001' \
  -d '{
    "debit_wallet": "USD",
    "amount": 250,
    "beneficiary_details_id": 42,
    "customer_id": "da44a3e6-eb5d-429f-8d17-357aa5a6cdf2",
    "reference": "INV-2026-0042"
  }'
```

```javascript Node.js
const response = await fetch('https://api.yativo.com/api/v1/payout/simple', {
  method: 'POST',
  headers: {
    'X-Api-Key': process.env.YATIVO_API_KEY,
    'X-Api-Secret': process.env.YATIVO_API_SECRET,
    'Content-Type': 'application/json',
    'Idempotency-Key': `payout-simple-${Date.now()}`,
  },
  body: JSON.stringify({
    debit_wallet: 'USD',
    amount: 250,
    beneficiary_details_id: 42,
    customer_id: 'da44a3e6-eb5d-429f-8d17-357aa5a6cdf2',
  }),
});
const data = await response.json();
```
</RequestExample>

## List Payouts

Retrieve a paginated list of all your payouts.

```
GET https://api.yativo.com/api/v1/payout/get
```

<RequestExample>
```bash cURL
curl -X GET 'https://api.yativo.com/api/v1/payout/get' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET'
```
</RequestExample>

## Get Single Payout

```
GET https://api.yativo.com/api/v1/payout/fetch/{payout_id}
```

<ParamField path="payout_id" type="string" required>
  The UUID of the payout to retrieve.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://api.yativo.com/api/v1/payout/fetch/txn-a1b2c3d4-e5f6-7890-abcd-ef1234567890' \
  -H 'X-Api-Key: YOUR_API_KEY' \
  -H 'X-Api-Secret: YOUR_API_SECRET'
```
</RequestExample>

## Payout vs. Wallet Payout

| | `POST /payout/simple` | `POST /wallet/payout` |
|--|---|---|
| **Beneficiary required** | Yes — `beneficiary_details_id` | Yes — `payment_method_id` + `customer_id` |
| **Quote support** | No | Yes — pass `quote_id` for locked rate |
| **Fix the receive amount** | No | Yes — `amount_type: "receive"` |
| **Use case** | Disbursements to saved beneficiaries | Single cross-currency payments with rate lock |

For a single payment where you want to lock a rate first, use `POST /exchange-rate` (with `method_type: "payout"`) → `POST /wallet/payout`. To fix what the customer receives rather than what you send, see [Pay out by receive amount](/yativo-fiat/exchange-rates#pay-out-by-receive-amount).
